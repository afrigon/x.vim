# x.vim

Vim support for the x programming language. Detects `*.x` files, highlights
the language's syntax — strings, characters, numbers, `t`/`f` booleans,
operators, keywords such as `fun`, `object`, `loop`, and `nil`, and `//`
comments — and provides C-style indentation and comment settings.

## Install

With Vim's native package support:

```sh
git clone https://github.com/afrigon/x.vim ~/.vim/pack/plugins/start/x.vim
```

With [vim-plug](https://github.com/junegunn/vim-plug):

```vim
Plug 'afrigon/x.vim'
```
